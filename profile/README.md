* **Web & Frontend:** React, Next.js, TypeScript

* **Enterprise First:** Clean architecture with strict separation of concerns (e.g., dedicated entity-DTO mappings via MapStruct).
* **Event-Driven:** Seamless, decoupled communication between service layers for maximum scalability.
* **Security & Performance:** Up-to-date dependencies, built-in vulnerability checks, and comprehensive SLF4J logging.
* **Modern UI:** Minimum three-color palette rule for consistent, accessible, and user-friendly interfaces.
